# ASCII Layout：上下文感知任务澄清

## Structure Sources

- PRD 第 7、8、9、10、11、12、16、17、19 节
- Obsidian 原生居中 Modal
- ATL 现有 `TaskConfirmationModal` 与 `MeetingTranscriptModal`

结构评审结果：`confirmed`。任务澄清是主链路，Agent 执行是简报保存后的可选区域。

## Screen Inventory

- TaskNotes 看板 / 日历：背景上下文，由 TaskNotes 继续拥有
- ATL 任务澄清 Modal：本期主界面
- 上下文明细 disclosure：查看、排除、重试来源
- 阻断性对话区：只在信息不足或用户主动提问时出现
- 冲突选择区：并列展示来源事实并等待用户选择
- 任务简报编辑区：目标、下一步、交付物 / 完成条件、范围与风险
- Agent 执行 disclosure：默认收起，可选展开
- 执行状态与结果区：只在真实启动后出现
- 评审状态切换器：仅存在于 standalone mockup

## Clarification Variant

```text
┌ 还缺 1 个关键决定 ───────────────────────────────────────────────────┐
│ AI：这次调研最终要服务哪个决定？                                    │
│ ○ 决定是否接入 TaskNotes  ○ 输出字段迁移方案  ○ 先记录风险          │
│ [补充你的回答……                                      ] [发送]       │
└──────────────────────────────────────────────────────────────────────┘
任务简报继续可见；未知字段标记“待确认”，不清空已有草稿。
```

## Conflict Variant

```text
┌ 目标存在冲突，请选择本次采用的依据 ─────────────────────────────────┐
│ ○ 来源笔记：只输出调研结论，不改代码             [打开来源]         │
│ ○ 任务描述：直接完成插件改造                     [查看原文]         │
│ ○ 两者都不采用，我补充最新目标                                      │
└──────────────────────────────────────────────────────────────────────┘
```

## Saved Manual Variant

```text
✓ 任务简报已保存
目标：明确 TaskNotes 与 ATL 的职责边界
下一步：对照现有字段列出保留、映射和隐藏项
完成条件：形成可评审的字段映射表

交给 Agent（可选） [>]

                               [继续编辑] [返回任务]
```

保存后的完整终点是“返回任务”。不要求 Agent、工作区、权限，不改变看板状态。

## State Model

| State | Trigger | Visible change | Primary action | Next / recovery |
| --- | --- | --- | --- | --- |
| sufficient | 上下文充分 | 显示完整草稿与来源标记 | 保存任务简报 | saved |
| clarify | 缺少阻断性决定 | 展开单问题对话，保留草稿 | 发送回答 | sufficient |
| conflict | 关键来源冲突 | 展示来源选项 | 采用所选依据 | sufficient |
| saved | 用户保存简报 | 显示简报摘要，Agent 收起 | 返回任务 | TaskNotes |
| agent-ready | 用户展开 Agent | 展示 Agent、工作区和权限 | 开始执行 | running / runtime-error |
| running | 会话已建立 | 展示当前步骤与会话入口 | 打开会话 | review / interrupted |
| review | Agent 返回结果 | 展示摘要、产物与验收操作 | 验收通过 / 要求修改 | done / running |
| model-error | 模型失败 | 原文和草稿保留，错误就地显示 | 重试 / 人工编辑 | sufficient / saved |
| runtime-error | Agent 不可用 | 不改变任务状态 | 重新检测 / 人工交接 | agent-ready / external |

## Dimensions And Scrolling

- 背景 Obsidian shell：占满视口。
- Modal：`width: min(860px, calc(100vw - 48px))`。
- Modal：`max-height: min(790px, calc(100vh - 110px))`，在 macOS 标题栏和底部评审状态切换器之间居中。
- Header 与 footer 固定在 Modal 内；body 独立纵向滚动。
- 上下文 chip 和元数据允许换行，不压缩标题。
- `1280 x 800` 下 Modal 仍居中；演示状态切换器移到底部单行滚动，不遮挡 footer。
- 不使用 Modal 内嵌卡片；主要区域用分隔线、背景 band 和 disclosure 建立层级。
